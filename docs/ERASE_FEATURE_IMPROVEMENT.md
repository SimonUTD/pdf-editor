# 擦除功能改进说明

## 改进时间
2026-01-28

## 问题描述
原有的擦除功能需要用户手动输入坐标(X, Y)和尺寸(宽度、高度)，这种方式极不友好，因为：
1. 用户无法直观知道坐标位置
2. 需要反复尝试才能定位到正确区域
3. 操作繁琐，体验极差

## 解决方案
改为**拖拽画框**的交互方式，类似 Photoshop 等专业软件：

### 实现方案
- **模式切换机制**：工具栏有"擦除"和"高亮"模式按钮
- **可视化反馈**：在 PDF 页面上直接拖拽绘制矩形框
- **实时预览**：拖拽过程中显示虚线框和半透明遮罩
- **智能确认**：松开鼠标自动执行操作

## 技术实现

### 1. 新增工具模式状态
```typescript
// src/stores/uiStore.ts
type ToolMode = 'view' | 'erase' | 'highlight';

interface UIStore {
  toolMode: ToolMode;
  setToolMode: (mode: ToolMode) => void;
}
```

### 2. 创建交互式 PDFCanvas
新组件：`src/components/PDFViewer/PDFCanvasInteractive.tsx`

**核心功能：**
- 监听鼠标事件（MouseDown, MouseMove, MouseUp）
- 在覆盖层 Canvas 上绘制选择矩形
- 虚线边框 + 半透明填充
- 实时计算并显示坐标

**视觉反馈：**
- 擦除模式：红色虚线框 (border: #ff4d4f)
- 高亮模式：黄色虚线框 (border: #ffec3d)
- 鼠标样式：crosshair（十字准星）
- 模式提示：左上角显示当前模式

### 3. 工具栏改进
```typescript
// 模式切换按钮
<Button
  type={toolMode === 'erase' ? 'primary' : 'default'}
  onClick={() => setToolMode(toolMode === 'erase' ? 'view' : 'erase')}
>
  {toolMode === 'erase' ? '退出擦除' : '擦除'}
</Button>
```

**按钮状态：**
- 普通模式：灰色按钮
- 激活模式：主色/红色高亮按钮
- 按钮文字动态切换：显示功能或"退出"

### 4. 操作流程

#### 擦除内容
1. 点击工具栏"擦除"按钮（进入擦除模式）
2. 鼠标移动到 PDF 页面上（显示十字准星）
3. 按下鼠标左键并拖拽绘制矩形框
4. 松开鼠标自动执行擦除
5. 白色矩形覆盖该区域内容
6. 再次点击"退出擦除"或点击其他按钮退出模式

#### 高亮区域
1. 点击工具栏"高亮"按钮
2. 在 PDF 页面上拖拽绘制矩形框
3. 松开鼠标自动添加黄色半透明高亮
4. 点击"退出高亮"返回普通模式

## 智能保护

### 误操作过滤
- 拖拽距离小于 5px：视为误操作，自动忽略
- 只在非查看模式下响应拖拽
- 自动将坐标限制在 canvas 范围内

### 坐标转换
```typescript
// 屏幕坐标 → PDF 页面坐标（考虑缩放）
const x = dragX / zoom;
const y = dragY / zoom;
const width = dragWidth / zoom;
const height = dragHeight / zoom;
```

## 技术细节

### Canvas 分层
1. **底层**：PDF 渲染层（pdfDocument）
2. **顶层**：交互覆盖层（pointerEvents: 'none'）
3. **容器**：事件监听层

### 性能优化
- 使用 `requestAnimationFrame` 优化绘制
- 仅在拖拽时重绘覆盖层
- 避免频繁的状态更新

### 可扩展性
此架构可轻松扩展支持其他工具：
- 矩形选择工具
- 自由绘制（手绘）
- 文本框选择
- 图片裁剪
