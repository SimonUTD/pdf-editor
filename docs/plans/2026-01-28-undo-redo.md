# 撤销/重做功能实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**目标:** 实现完整的撤销/重做系统，支持所有PDF编辑操作的可逆执行

**架构:** 使用 Command Pattern 模式，每个编辑操作封装为独立的命令对象，维护命令历史栈，实现 execute/undo/redo 三态操作

- 工具栏按钮：撤销/重做
- 快捷键：Ctrl+Z（撤销）、Ctrl+Y（重做）、Ctrl+Shift+Z（重做）
- 仅支持自定义快捷键，不覆盖浏览器/系统原生快捷键

**Step 1: 创建命令基类**

```typescript
// src/commands/BaseCommand.ts
export interface BaseCommand {
  execute(): Promise<void>;
  undo(): Promise<void>;
  redo(): Promise<void>;
}

export abstract class Command implements BaseCommand {
  abstract execute(): Promise<void>;
  abstract undo(): Promise<void>;

  async redo(): Promise<void> {
    // 默认 redo 与 execute 相同
    return this.execute();
  }
}
```

**Step 2: 创建图片插入命令**

```typescript
// src/commands/ImageInsertCommand.ts
import { PDFDocument } from 'pdf-lib';
import { Command } from './BaseCommand';
import { ImageObject } from '@/types/objects';

export class ImageInsertCommand extends Command {
  constructor(
    private pdfDoc: PDFDocument,
    private imageObject: ImageObject,
    private imageBytes: Uint8Array,
    private onExecute?: (obj: ImageObject) => void,
    private onUndo?: (id: string) => void
  ) {
    super();
  }

  async execute(): Promise<void> {
    // 1. 在 PDF 上绘制图片
    const page = this.pdfDoc.getPage(this.imageObject.pageIndex);
    const image = await this.pdfDoc.embedPng(this.imageBytes);

    page.drawImage(image, {
      x: this.imageObject.position.x,
      y: this.imageObject.position.y,
      width: this.imageObject.size.width,
      height: this.imageObject.size.height,
    });

    // 2. 添加到对象存储
    if (this.onExecute) {
      this.onExecute(this.imageObject);
    }
  }

  async undo(): Promise<void> {
    // TODO: 从 PDF 移除图片（需要重新生成页面）
    // 临时方案：从对象存储移除
    if (this.onUndo) {
      this.onUndo(this.imageObject.id);
    }
  }
}
```

**Step 2: 创建命令历史管理**

```typescript
// 在 App 组件内
const [commandHistory, setCommandHistory] = useState<Command[]>([]);
const [commandIndex, setCommandIndex] = useState(-1);

const executeCommand = async (command: Command) => {
  await command.execute();

  // 截断"未来"历史
  const newHistory = commandHistory.slice(0, commandIndex + 1);
  newHistory.push(command);

  // 限制历史长度
  if (newHistory.length > 100) {
    newHistory.shift();
  }

  setCommandHistory(newHistory);
  setCommandIndex(newHistory.length - 1);
  markAsUnsaved();
};

const undo = async () => {
  if (commandIndex < 0) return;

  const command = commandHistory[commandIndex];
  await command.undo();
  setCommandIndex(commandIndex - 1);
  markAsUnsaved();
};

const redo = async () => {
  if (commandIndex >= commandHistory.length - 1) return;

  const command = commandHistory[commandIndex + 1];
  await command.redo();
  setCommandIndex(commandIndex + 1);
  markAsUnsaved();
};
```

**Step 2: 添加撤销/重做快捷键**

```typescript
// src/hooks/useKeyboardShortcuts.ts
import { useEffect } from 'react';
import { useEditStore } from '@/stores';

interface ShortcutOptions {
  onUndo?: () => void;
  onRedo?: () => void;
}

export const useKeyboardShortcuts = (options: ShortcutOptions = {}) => {
  const { toolMode, setToolMode } = useUIStore();

  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      const isModKey = e.ctrlKey || e.metaKey;

      // 撤销: Ctrl+Z 或 Cmd+Z
      if (isModKey && e.key === 'z' && !e.shiftKey) {
        e.preventDefault();
        if (options.onUndo) {
          options.onUndo();
        }
      }

      // 重做: Ctrl+Y 或 Cmd+Y
      // 或者 Ctrl+Shift+Z / Cmd+Shift+Z
      if (
        (isModKey && e.key === 'y') ||
        (isModKey && e.shiftKey && e.key === 'z')
      ) {
        e.preventDefault();
        if (options.onRedo) {
          options.onRedo();
        }
      }

      // ESC: 退出工具模式或取消选择
      if (e.key === 'Escape') {
        if (toolMode !== 'view') {
          setToolMode('view');
        }
      }
    };

    document.addEventListener('keydown', handleKeyDown);
    return () => document.removeEventListener('keydown', handleKeyDown);
  }, [toolMode, setToolMode, options.onUndo, options.onRedo]);
};
```
